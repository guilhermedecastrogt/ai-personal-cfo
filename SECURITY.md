# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through [GitHub's private vulnerability reporting](https://github.com/guilhermedecastrogt/ai-personal-cfo/security/advisories/new).

Include what is affected, how to reproduce it and what an attacker could do. You will get an acknowledgement as soon as possible; this is a personal project, so there is no fixed response time.

## Scope

In scope: the code in this repository, including the API, the dashboard, the WhatsApp webhook, authentication and household isolation.

Out of scope: third-party services (OpenAI, Kapso, Meta, Oracle Cloud) and self-hosted deployments that changed the configuration.

The controls that exist, and what they do not cover, are described in [docs/security.md](docs/security.md).
